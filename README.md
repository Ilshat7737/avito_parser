# Avito Monitor

Локальный мониторинг объявлений Avito: отслеживает появление новых
объявлений и изменение цены по заданному поисковому запросу.

## Установка

```bash
python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate

pip install -r requirements.txt
playwright install chromium     # ставит браузер для Playwright
```

## Настройка

Откройте `config.py` и укажите:

1. **SEARCH_URL** — ссылка на страницу поиска Avito с нужными фильтрами
   (город, категория, цена и т.д.). Проще всего настроить фильтры прямо
   на сайте и скопировать адрес из браузера.
2. При желании — интервал проверки, Telegram-уведомления и т.д.

## Запуск

```bash
python main.py            # непрерывный мониторинг, Ctrl+C для остановки
python main.py --once     # одна проверка (удобно вызывать по cron / Task Scheduler)
```

Найденные объявления сохраняются в `avito_monitor.db` (SQLite) —
файл можно открыть, например, DB Browser for SQLite, чтобы посмотреть
всю историю.

## Как это устроено

- `scraper.py` — открывает страницу поиска в браузере (Playwright) и
  парсит карточки по атрибутам `data-marker` (они меняются реже, чем
  CSS-классы). Для новых объявлений дополнительно заходит на страницу
  объявления за полным описанием.
- `db.py` — хранит уже виденные объявления в SQLite, чтобы отличать
  новые от старых и ловить изменение цены.
- `notify.py` — выводит уведомления в консоль и опционально шлёт их в
  Telegram.
- `main.py` — цикл: проверка → сравнение → уведомление → пауза (с
  небольшим случайным разбросом, чтобы не стучаться в одно и то же
  время).

## Важно

- Avito ограничивает частоту запросов и может временно блокировать по
  IP при слишком активном парсинге — не уменьшайте `CHECK_INTERVAL_SEC`
  слишком сильно и не убирайте задержки в `config.py`.
- Массовый сбор чужих объявлений может противоречить пользовательскому
  соглашению Avito, а сбор персональных данных (телефоны, адреса и
  т.п.) регулируется 152-ФЗ — используйте инструмент для мониторинга
  собственного интереса (например, поиска покупки), а не для
  накопления баз данных о третьих лицах.
- Разметка сайта время от времени меняется — если парсер перестал
  находить объявления, проверьте актуальные `data-marker` в DevTools
  браузера (F12 → выделить карточку объявления).
